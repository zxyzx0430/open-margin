Windows 一键部署

让手机记账，自动同步到这台电脑

向导会检查并安装运行环境，启动清衡服务，开启一个只用于同步的公网入口。大约 10–30 分钟，取决于网络。

不需要提前安装 Docker、Tailscale、Git 或 Python。

Docker Desktop 许可确认

安装器已记录你的 Docker 许可确认，可以继续安装依赖。

当前向导不是以管理员权限运行（可能是通过 /NOELEVATE 启动）。环境检查会提示管理员权限失败；点“一键安装依赖”时仍会弹出 UAC 并请求提权。

安装依赖会弹一次 Windows 管理员确认（UAC）。如果 Docker 镜像下载失败，可以使用离线镜像包。

第 2 步

连接 Tailscale

手机不需要安装 Tailscale。

Tailscale 只给这台电脑一个公网 HTTPS 入口。手机用自己的商业 VPN 访问这个入口，不会和 VPN 抢通道。

确认

公网访问说明

部署完成后，这台电脑会有一个公网地址，只开放：

  • 健康检查（GET /finance/health）
  • 同步接口（GET /finance/api/v2/sync/changes）
  • 同步推送（POST /finance/api/v2/sync/push）
  • 两个旧版 Android 同步接口

Wallos 账本、MCP、OAuth 和管理接口不会对公网开放。

二维码相当于账本钥匙。不要截图、不要转发，10 分钟后向导会自动隐藏它。
