Windows 一键部署

让手机记账，自动同步到这台电脑

向导会检查并安装运行环境，启动清衡服务，开启一个只用于同步的公网入口。大约 10–30 分钟，取决于网络。

不需要提前安装 Docker、Tailscale、Git 或 Python。

第 1 步

环境检查

安装依赖会弹一次 Windows 管理员确认（UAC）。如果 Docker 镜像下载失败，可以使用离线镜像包。

第 2 步

连接 Tailscale

手机不需要安装 Tailscale。

Tailscale 只给这台电脑一个公网 HTTPS 入口。手机用自己的商业 VPN 访问这个入口，不会和 VPN 抢通道。

确认

公网访问说明

部署完成后，这台电脑会有一个公网地址，只开放：

  • 健康检查（GET /finance/health）
  • 同步接口（GET /finance/api/v2/sync/changes）
  • 同步推送（POST /finance/api/v2/sync/push）
  • 两个旧版 Android 同步接口

Wallos 账本、MCP、OAuth 和管理接口不会对公网开放。

二维码相当于账本钥匙。不要截图、不要转发，10 分钟后向导会自动隐藏它。

第 3 步

设置管理员账号

这是以后登录网页版清衡的账号。密码只用于本地创建管理员，不会写进日志。

第 4 步

一键部署

等待开始

打开授权页

部署过程中可能会弹出 Tailscale 授权页，点“允许”即可。不要关闭这个页面。

2. 扫码配对

二维码 10 分钟后自动隐藏，只在本机显示。

手机上还要做

  1. 打开 App → 自动记账设置 → 授权通知使用权（必需）、短信（可选）、无障碍页面识别（可选）、电池优化白名单。
  2. 设置 → 扫码连接 → 扫描上面的配对二维码。
  3. 点“测试连接”，看到账本身份和同步进度就成功了。
注意
  • 电脑要保持开机；休眠/关机时同步暂停，手机继续本地记账，恢复后补传。
  • 二维码和密钥不要截图、不要转发。
  • 建议点“一键备份”；本机备份不等于异地备份。
  • 关闭远程访问：下面点“关闭远程同步”，数据不会删除。
