# 清衡 v1.3.1-rc.3（RC）

设置页补齐了「反馈」和「关于」，录音也处理了外放音乐干扰。仍是预发布。

## 录音

- 开启回声消除（AEC）与降噪；不可用时自动退到 `VOICE_COMMUNICATION` 音源。
- 录音期间请求瞬时独占音频焦点：放歌时长按说话，音乐暂停，停止后恢复。
- 松手不结束录音，只有面板「停止」才结束。

## 设置

- 新增「反馈问题」：邮件（工作邮箱 zxyzx0430@outlook.com）或 GitHub Issue，两种方式共用同一份诊断信息。
- 诊断信息只含版本、机型、Android 版本、语言；不含金额、商户、账户或日志内容。
- 新增「关于清衡」：版本、工作邮箱、GitHub 仓库、GPL-3.0 许可、隐私说明。
- 「配对电脑」页右上角固定「扫一扫」，点开直接扫码，不必先读完说明；下方仍可手动填写地址和密钥。
