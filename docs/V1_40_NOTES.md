# 清衡 1.40

`versionCode 41` / `versionName "1.40"`

## 新手引导

- 首次启动展示一页「新手必看」：自动记账、手动和语音记账、账单查看与修改、日历统计与预算、导入微信支付宝账单
- 「开始使用」或「跳过」完成；已有账单的老用户不弹
- 设置页可「重看引导」
- 通知使用权只在点「开启自动记账」后跳系统设置，返回时检查；成功后才在 Android 13+ 请求通知权限

## 同步设置

- 「同步设置」与「最近同步」两个入口重复，删掉前者，后者改名「同步状态」
- 同步状态按连接情况显示颜色：已连接绿色，重试/鉴权失败红色，未配置或未同步灰色
- 扫码、重新配对、手动填写合并进同一张服务器卡片，不再有两套入口和两套错误提示

## 待处理

- 待处理不再跳同步设置，改为独立页面
- 没有冲突时显示「暂无冲突」
- 有冲突时逐笔展开：本机与服务器两侧内容、不一致字段，可直接保留本机或采用服务器

## 关于与更新

- 删除重复的「当前版本」行，版本号只保留在「关于清衡」

## 其他

- 后端：设备完成鉴权同步后上报状态，电脑端向导能判断手机是否真的连上
- 后端：向导探测请求不再计入设备同步记录
- Windows：安装脚本适配 PowerShell 5.1，修复探测模式与手机状态向导动作

## 已知

- 通知点击不跳账单详情
- 多语言只跟随首次启动的系统语言
- 更新包约 120MB，不支持断点续传
