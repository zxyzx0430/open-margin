# 同步设置独立页

## 信息层级

页面通过 `sync-settings` 独立路由打开，顶部栏显示「同步」和返回箭头；返回时 `popBackStack()` 回到原设置页，不占底部导航。

从上到下：

1. **状态卡（最高优先级）**：28sp 状态词（已连接、未配置、同步异常等），下一行显示省略中段的服务器地址，再显示上次成功时间；待上传与冲突分成两个 28sp 数字。同步正在排队或运行时显示进度条，「立即同步」按钮禁用并显示「同步中」。
2. **服务器卡**：地址与密钥各一行，完整值可复制；密钥默认显示 `••••••`，可临时显示或复制。地址文本做中段省略，复制始终使用原值。重新配对直接打开扫码。
3. **配对服务器卡**：只保留一句「扫码或手动填写服务器地址与设备密钥」，行内可直接扫一扫，另有手动填写入口。扫码解析后复用已有只读账本身份验证向导；手动入口直接落到地址/密钥表单步骤。
4. **高级卡（默认折叠）**：接入现有自动同步开关。当前没有仅 Wi-Fi 配置，不新增该开关。重置连接使用二次确认。

卡片圆角 18dp，卡间距 12dp，页面沿用 MaterialTheme 背景与配色。地址、密钥与计数的说明文本限制在一至两行。

## 交互与安全边界

- 设置列表中的「同步设置」行和同步状态卡都导航到同一独立页；配对入口收进该页。
- 手动同步通过既有 `TransactionSyncWorker.requestImmediate()` 发起；页面同时观察 WorkManager 的立即任务与周期任务（周期任务只在 RUNNING 时显示进度），不改变上传与冲突处理。冲突数大于零时提供「查看冲突」，复用现有逐笔冲突处理面板，避免丢失处理入口。
- 复制密钥仅写入系统剪贴板；界面默认脱敏，代码不记录密钥日志。
- 「重置连接」确认后关闭自动同步、清除保存的服务器地址和密钥，并取消周期/立即任务。保留本机交易、上传/冲突数据、同步游标和服务器账本身份，防止重置后重复上传或误连另一账本；若要切换账本仍须先做显式迁移。
- 未配置「仅 Wi-Fi」开关，因此不添加。

## 真机待验

- 长地址在状态卡和服务器行中段省略，复制后仍是完整地址。
- 密钥默认脱敏；显示/隐藏与复制结果正确，复制操作不产生日志。
- WorkManager 排队、运行时按钮禁用并显示进度；结束后状态与计数刷新。
- 未配置、授权失败/同步异常、已连接状态的颜色与文案正确。
- 相机拒绝、无效二维码、有效二维码、手动地址/密钥填写及账本身份校验流程正确。
- 重置连接二次确认；重置后本地交易与同步账本身份仍保留。

## 统一配对域名

扫码和手动入口共用同一校验：必须是 DNS 主机名、HTTPS、无账号信息/查询参数/片段/显式端口，路径为 `/finance`。普通 VPS 域名和 Tailscale `*.ts.net` 域名都支持；不允许本机地址。旧连接配置与同步游标不变。
