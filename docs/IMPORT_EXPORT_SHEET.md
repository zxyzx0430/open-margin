# 账单导入 / 导出面板

## 入口与导入流程

设置 →「导入账单」打开底部面板，不新增全屏导航路由。面板提供「选择账单文件」和「导出全部账单」；选择文件后，现有微信 / 支付宝 CSV、XLSX、文本解析与预览在同一面板中完成。只有用户点「确认导入」后才写入账本；解析器与导入映射逻辑不变。关闭或取消文件选择会留在设置页。

账单页原有的独立导入路由保留给仍使用它的入口。导入期间禁止关闭面板，避免取消正在进行的事务写入。

## 导出格式

使用系统 `ACTION_CREATE_DOCUMENT` 选择保存位置，默认文件名为 `清衡账单-YYYYMMDD.csv`（设备本地日期）。导出查询当前未软删除的全部交易，不按统计类型或审核状态筛选；无交易时仍生成只有表头的文件。

- 编码：UTF-8，带 BOM；记录行使用 CRLF。
- 时间：`yyyy-MM-dd HH:mm:ss`，按设备当前时区格式化。
- 金额：从整数分精确换算为元，固定两位小数，不使用浮点数或千位分隔符。
- 含逗号、双引号或换行的字段按 RFC 4180 规则加引号，内部双引号重复转义；空商户 / 账户保留为空字段。

| 顺序 | 中文表头 | 来源 |
| --- | --- | --- |
| 1 | 时间 | 交易时间戳 |
| 2 | 类型 | 支出 / 收入 |
| 3 | 金额（元） | 金额分精确换算 |
| 4 | 分类 | 分类显示名 |
| 5 | 商户 | 商户，可为空 |
| 6 | 账户 | 账户，可为空 |
| 7 | 来源 | 手动、微信、支付宝、银行短信等 |
| 8 | 备注 | 用户备注，可为空 |

导出只读取本机数据，不更改账本。取消保存位置选择不创建文件；写入失败时面板显示失败提示。

## 边界

- 软删除记录（`syncDeleted = true`）不导出；其他记录不因重复标记、审核状态、来源或统计口径被过滤。
- 导出不上传数据、不修改数据库结构，也不改变导入解析器、去重或确认逻辑。
- 文件访问由系统文档选择器授权；真机需检查不同文件提供方下的创建、覆盖和取消行为。
