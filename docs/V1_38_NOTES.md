# 清衡 v1.38

正式版。语音面板与手动面板统一到同一个底部面板组件，并修掉发版前扫出来的几处边界问题。

## 面板统一

- 语音记账面板改用与「新建账单」「导入 / 导出账单」相同的 `ModalBottomSheet`：同样的遮罩、拖柄、下滑关闭、窗口级覆盖。
- 手动新建账单仍是同一个组件，字段布局不变。
- 保存过程中禁止下滑关闭面板（关闭按钮同时禁用），写入失败时表单一定还在，可以直接重试。

## 语音

- 面板打开后不再把触摸中断误判成「滑出取消」，避免刚开始录音就被结束。
- 录音仍然只能通过面板上的「停止 / 取消」结束。

## 设置

- 「自动记账设置」重新有入口：设置 → 权限与运行状态下方一行，点开是原来的开启向导（通知、页面识别、无障碍回退）。

## 已知未修

- 自动记账成功通知点击仍只打开 App，不直接跳到那笔账单详情（留到下一版）。

## 版本

- versionCode 38 / versionName 1.38；覆盖安装保留数据。
