# 清衡 1.44

`versionCode 45` / `versionName "1.44"`

## 自动采集去重与 ColorOS 稳定性修复

- 排除微信/支付宝账单流水列表页的被动无障碍识别（保留单笔账单详情页与支付凭证页），消除翻看账单时误抓历史流水和汇总大额的问题
- 为页面识别与待确认队列增加页面身份节流及同交易去重，避免同一笔转账/红包反复入队多次；待确认弹窗支持二次确认「全部忽略」
- 修复微信聊天界面单笔已收款转账（`已被接收` + `已收款`）双气泡同时记成支出和收入的问题，合并为单笔收入
- 屏蔽后台相册自动监听对非交易图片与临时未落盘图片的红条报错，并对 ColorOS/MIUI 落盘延迟增加短暂重试与水位线推进
- ColorOS 16+ 使用系统 `NotificationManager.isNotificationListenerAccessGranted` 校验通知使用权，点击采集状态可主动触发 `requestRebind` 重连

## 重复合并、无障碍简化与批量整理

- 「待确认重复」卡片支持一键「**合并为一笔**」，保留原记录主 ID，自动吸取更具体商户名、非 `OTHER` 分类、官方单号、账户与去重备注，并软删除重复记录
- 无障碍引导与设置页收敛为单一「清衡 · 页面识别」服务（4 步向导），写明系统路径与开关名称，设置页隐藏多余旧版兜底入口
- 设置「商户分类记忆」与统计页「其他」分类支持按归一化商户聚合批量整理，可选回溯全部历史同类记录并自动触发同步；弱占位商户名保持单笔隔离不误存规则
- 日历抽屉明细统一复用 `LedgerTransactionRow`，展示商户头像、来源徽章、自适应金额与可独立展示的手工备注

## 诊断日志可见性与 4 段式排障包

- 新增持久化 `ServiceHealthLog`（最近 80 条服务连接/断开/重连、静默丢弃与相册水位轨迹），在诊断页顶部「采集运行概览」支持一键展开查看
- 日志卡片展示中文人话语义结果（`已自动记账 / 转入待确认 / 已去重忽略 / 已跳过 / 处理失败`）与通俗原因说明；支持按来源通道与结果状态筛选，并与「导出排障日志」共用筛选范围
- 「导出排障日志」改版为原生底部面板，默认开启附带原始抓取文本（可关闭脱敏），支持保存 `.txt` 或分享 4 段式排障包
