# 清衡 v1.2.0-rc.11

- 账单导入不再把 0 元授权、失败/关闭交易算成“解析错误”；分开显示“可导入 / 可补齐 / 已跳过 / 错误”。
- “不计收支”按转账/账户内部流动入账，保留支付宝交易分类，统计排除。
- 重复账单不再直接丢弃：用完整账单补齐旧记录缺失的商户、单号、支付方式和分类，不覆盖手工记录。
- 分类器升级为结构化输入：方向、来源、交易类型、状态、官方来源分类；15 个分类全部保留，新增具体短语、来源分类、退款/转账 POST 规则。
- 新增学习闭环：同一商户连续两次一致修正且严格多数后生效；支持按商户暂停/恢复学习。
- 页面识别开启增强 WebView 无障碍；复核弹窗默认分类不再固定“其他”。
- 真实支付宝年度账单回归：415 行 → 346 可导入、69 跳过、0 解析错误。
