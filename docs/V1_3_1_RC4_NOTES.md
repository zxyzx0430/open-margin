# 清衡 v1.3.1-rc.4（RC）

这一版主要在补界面：日历、记账、扫码、导入导出、同步设置，都按实际使用重排了层级。

## 日历

- 点某一天，下方直接显示当天明细：支出 / 收入 / 结余 + 该日账单列表，默认选中今天。
- 日历区域左右滑动切换日期，跨月自动切月。
- 切上 / 下月会提示「已切换到 2026 年 12 月」，回到本月提示「已回到本月」。

## 记账

- 新建账单压成一屏，不再上下滑动：日期与金额同行，账户选项单行横向滚动。

## 扫码配对

- 扫码页改成相机观感：全屏预览、黑色蒙层、白色四角取景框、手电筒开关。
- 「配对电脑」页右上角固定「扫一扫」，点开直接扫码。

## 导入 / 导出

- 设置里「导入账单」不再跳整页，改成底部面板，导入预览和确认都在面板里。
- 新增「导出全部账单」：CSV（UTF-8 BOM、中文表头），金额精确到分。
- 导出教程更新：微信、支付宝都支持「应用内接收」，无需邮箱、无需解压。

## 同步设置

- 独立页面：顶部状态卡（已连接 / 未配置 / 异常 + 上次同步时间 + 待上传 / 冲突数）、「立即同步」主按钮；服务器地址与密钥分行展示，密钥默认脱敏；配对与高级选项分开。

## 设置页层级

- 「反馈问题」并入「关于与更新」卡，不再单独占一个分组。
- 「导入账单」与「导出账单教程」放在同一张卡，对齐一致。

- 覆盖安装保留账本数据。
