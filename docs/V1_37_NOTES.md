# 清衡 v1.37

新建账单面板改成和「导入 / 导出账单」同一种底部面板。

## 改了什么

- 之前的手动面板是自绘遮罩：只盖住页面内容区，底部导航栏露在外面，所以看着像页面内弹窗。
- 现在直接复用 `ModalBottomSheet`，与导入/导出账单完全同一个组件：窗口级遮罩、下滑关闭、默认拖柄、高度跟随内容（上限 720dp）。
- 标题样式、关闭按钮、横向 20dp / 底部 16dp 内边距也与导入/导出面板一致。
- 一句话记账的四行示范与字段提示保留。

## 版本

- versionCode 37 / versionName 1.37；覆盖安装保留数据。
