# 清衡 v1.3.1

这一版的主线是**语音记账**，以及语音接入后暴露出来的保存前校验问题。

## 语音记账

- 本地流式识别：sherpa-onnx + `pkufool/zipformer-medium-streaming` 流式 CTC INT8，模型内置，录音与转写不出设备。
- 交互：长按「+」满 1 秒立刻开始录音并弹出面板；说话时实时上屏，**可以直接改**；松手即停，面板留在原地核对。
- 编辑保护：手动改过的文字不会被后续识别结果覆盖；识别结果有更新时给「识别更新了，点此替换」，由你决定。
- 收尾补 0.6 秒静音，避免「三十块钱」被截成「三十」这种金额少一位的问题。
- 语音只是录入方式：新增账单来源仍是手动，不会伪装成微信/支付宝采集。
- 引擎常驻：启动后后台预热，连续记账不用反复等模型。
- 中文解析 149 条测试；英文解析 91 条测试（金额、方向、商户、账户、时间、分类）。

## 保存前检查与账户

- 疑似重复提示：同金额同商户（说了钟点 1 小时内 / 只说了日期当天）、同金额任意商户 10 分钟内，保存前提示；默认「取消」，可「仍然记这一笔」。
- 重复判断带收支方向与币种，收入和支出、不同币种不会互相误报。
- 新增「账户」选择（微信 / 支付宝 / 现金 / 银行卡 / 不填），解析出的「微信支付」会写进账户字段；详情页非空才显示。
- 账户仅保存在本机，不同步到服务端（隐私设计）。

## 其他

- 分类预填走商户记忆：显式规则 > 学到的纠正 > 内置关键词 > 解析器默认。
- 版本号：versionCode 26 / versionName 1.3.1。

## 已知边界

- 语音仅支持单笔；一句话两笔只取第一笔并提示。
- 外币不换算；欧元/英镑/日元金额留空并提示。
- 英文不解析具体钟点（`at 7pm` 不认）。
- 需真机验证麦克风、震动、键盘上推、内存与首字延迟。
