# P8 floating navigation and ledger scroll

P7 screenshot showed calendar and ledger drawn over each other. NavHost had an incoming 120ms fade with exit None and calendar did not own an opaque background. Both are fixed: all route-level transitions are None, calendar owns a full opaque canvas, main tab host size is constant, floating chrome is a sibling overlay rather than a Scaffold bottom slot. Calendar content retains its previous safe bottom reserve to keep the live drawer clear. All scrolling tabs reserve the full overlay height in their existing scroll/FAB padding. Native system nav contrast scrim disabled, selected tab uses rounded inset fill, repeated selected-tab tap is ignored. Enhanced is the default for unset preferences; stored explicit choices are retained and accessibility/device fallbacks remain. During scrolling, enhanced uses lightweight translucent tint and highlight; native blur returns idle. No claim of real-time native blur while scrolling.

Ledger: native clickable provides press arbitration; scaling is drawn only on a real press, no separate per-row graphics layer or competing pointer observer. Haptic only on click. Bring-into-view and highlight effects allocated only for the affected row. Amount formatting remembered, ordinary category/merchant avatars skip the image loading coroutine, rectangular interior rows skip rounded clipping. Keep P6 lazy row layout, full currency amounts, grouping, navigation, calendar drawer and VoiceFab design unchanged. No capture or accounting logic changes.

ADB was disconnected at implementation time; frame-rate gains and screenshot regression must be confirmed on device. CI is the build/test gate, not evidence of subjective smoothness.
