# 清衡 v1.2.0

首个 1.2.0 正式版，包含此前的 rc 系列功能和本次稳定性修复。

- 采集：通知、短信、无障碍页面/OCR、官方账单导入统一进入账本；修复微信聊天列表误记、聚合汇总通知重复入账。
- 导入：0 元/失败/关闭单独跳过；不计收支按转账入账；重复行补齐商户/单号/支付方式。
- 分类：15 个分类、商户归一化、官方交易分类、具体短语规则、退款/转账安全规则；用户修正学习。
- 统计：月度/全年/按日；按日可选择年月日并默认今天；统计包含转账、退款等全部真实 CNY 流水，只排除已排除和重复记录。
- UI：独立日历 Tab（单日/区间/跨月/农历/热力）、账单全部账单视图、分类底部面板、统计分类下钻、设置页对齐。
- 稳定性：修复 rc.13 启动闪退；rc.14 增加崩溃捕获与 arm64-only release。

版本：versionCode 19，versionName 1.2.0
