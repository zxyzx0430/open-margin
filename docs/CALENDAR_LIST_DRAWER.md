# 日历账单列表抽屉

## 展示规则

- 单日或日期区间选中后，日历下方显示非模态列表抽屉；未选中时不创建抽屉，维持本月汇总卡。
- 抽屉高度相对于日历内容区可用高度：默认 **40%**，展开 **85%**；初次选中默认从 40% 开始。
- 顶栏包含 40×4dp 圆角把手、单行省略的日期与账单数、清除选择和收起动作。英文日期采用短格式，例如 `Nov 17 · 3 items`；数量为 1 时使用 `item`。
- 选中日期/区间的支出、收入、结余和笔数继续显示在原汇总卡中，卡片位于抽屉顶栏下方；账单为空时仍显示抽屉与本地化空状态（单日「这天没有记账」，区间「这段时间没有记账」）。
- 抽屉没有模态遮罩，锚点高度变化只覆盖日历下方区域；没有选中时不留下空抽屉。

## 锚点与吸附

- `CALENDAR_DRAWER_COLLAPSED_FRACTION = 0.40f`
- `CALENDAR_DRAWER_EXPANDED_FRACTION = 0.85f`
- 向上拖动把手增加高度，向下拖动把手减少高度；释放时比较当前高度与两个锚点的距离，吸附到最近锚点，动画 180ms。顶栏「收起 / Collapse」直接回到 40%。
- 高度基于父级 `BoxWithConstraints.maxHeight`，即外层 Scaffold 留出的内容高度，不依赖设备固定像素或状态栏全屏尺寸。

## 手势边界

- `draggable` 只绑定顶栏把手的 44×40dp 触摸区，视觉把手本身为 40×4dp；标题、清除按钮不接管纵向拖动。
- 列表由抽屉内部独立的 `LazyColumn` 滚动。列表区域没有父级纵向 draggable/scrollable，避免上拉展开与账单滚动互相抢手势。
- 日历网格仍使用原来的点选、长按拖选、跨月和手势识别代码；抽屉之外仍可触达的网格区域保持原有交互。被抽屉覆盖的部分自然不可点，不加模态 scrim 或拦截层。

## 测试

纯 JVM 测试验证两个锚点、中英文标题/单复数和单日/区间空状态。Compose 拖动与触摸分发无法由这些纯 JVM 单测证明；CI 的 APK 构建只证明编译通过，真机仍需检查：上拉展开、下拉收起、释放最近锚点、列表滚动、无记录空状态，以及未遮挡网格的点选/长按跨月操作。
