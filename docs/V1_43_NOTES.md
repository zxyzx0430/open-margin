# 清衡 1.43

`versionCode 44` / `versionName "1.43"`

## 清衡账单完整往返导入

- 支持直接导入清衡导出的 CSV 账单（`时间,类型,金额（元）,分类,商户,账户,来源,备注`），完整还原原分类、账户、来源与备注
- 修复导入清衡导出文件时因缺少状态列被误跳过、空商户自动抓取记录报错以及二次导入误标「可补齐」的问题

## 统计与列表体验优化

- 统计页点击「查看某日账单」改为当页直接弹出当日明细弹窗，无需跳转账单页，也不再出现退不出的问题；账单页筛选视图同步补充一键「全部账单」返回入口
- 顶部汇总卡片（支出 / 收入 / 结余）金额改为按容器宽度自适应缩放，大额数字不再被截断
- 移除账单列表商户名旁冗余的 `· 转账` 等状态后缀，列表更清爽
- 重新设计「待确认重复」提示卡片；已忽略截图弹窗支持单条删除、一键清空与点击预览原图
- 修复账单详情页与编辑页顶部状态栏及摄像头打孔遮挡问题
