# 清衡 · Open Margin 长期迭代路线图（Roadmap）

> **更新日期**：2026-11-24
> **当前基线**：Android `v1.46`（`versionCode 47`）· Windows 安装器（含 4 段式排障日志一键导出）· 设计规范 [`docs/DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md)
> **产品边界**：本地优先、零广告、零核心功能付费墙（离线语音、批量截图 OCR、自动采集、订阅、预算、导入导出全部开源免费）；不内置 AI 聊天窗口或大模型 API，AI 分析通过外部客户端对接清衡 MCP 服务实现。

## 0. 已完成基线回顾（v1.42 – v1.46）

- **`v1.42`**：主动批量截图导入（最多 10 张）+ 本机原图留证、三手势 FAB、自研滚轮日期时间选择器、设置页分组与站内更新提示。
- **`v1.43`**：清衡导出 CSV 完整往返导入、统计页当日明细弹窗、顶部汇总金额自适应缩放、移除列表冗余状态后缀、翻新官网下载页与 4 屏实拍图。
- **`v1.44`**：待确认重复「合并为一笔」、无障碍收敛为单一「清衡 · 页面识别」、按商户批量整理「其他」分类与回溯、日历明细行视觉统一、4 段式排障日志导出。
- **`v1.45`**：直连 HTTP 流式下载与 Range 断点续传、三动作更新横幅（忽略此版本 / 下次再提醒 / 立即更新）、高频重复扫描修复、国产 OEM ROM 适配层、Windows 一键安装器 4 段式排障日志导出。
- **`v1.46`**：订阅与周期续费管理（Wallos 双向同步 + 到期前本地提醒 + 日历圆点与当日计划 + 候选续费自动探测）、统计页「支出 | 收入 | 订阅」三合一全景与账户分布、钱迹/一木/鲨鱼 CSV 一键搬家、全量单文件 `.zip` 备份与安全合并恢复、规则全量回溯。

## 1. 近期计划：`v1.47`（纯手机防丢 + 桌面轻感知）

> **目标**：零破坏现有数据库与 `sync_v2` 协议，把 `v1.46` 已有的 `.zip` 完整备份和预算/订阅能力延伸到“全自动防丢”和“手机桌面”。

### 1.1 WebDAV 自动备份与云端一键恢复（P0）
- 复用 `FullBackupManager` 单文件 `.zip` 机制，在「数据迁移与备份」中新增 **WebDAV 自动备份**。
- 内置 **坚果云 / 群晖 NAS / Alist / 自定义** 预设模板（自动填默认地址），提供「测试连接」与可读错误反馈。
- 支持 `WorkManager` 按日/按周 Wi-Fi 下静默自动上传（默认不含原图，保留最近 N 份滚动清理），换机后可拉取云端备份列表走现有「预览 + 安全合并恢复」。
- 凭据仅存本机安全存储，严禁写入日志或导出包。

### 1.2 Android 桌面小组件（Widgets，P0）
- 严格遵循 [`docs/DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) 清衡青绿视觉与深浅色自适应，只做高频「看钱」信息型小组件（不做冗杂记账工具栏）：
  - **`2×1` 本月收支 & 预算进度**：展示本月支出、剩余预算与进度条；未设预算时自动降级展示本月支出/结余。
  - **`4×2` 近期续费倒计时**：展示未来即将扣款的 2–3 条订阅、剩余天数、折合人民币金额与「准备取消」标记，点击直达日历/订阅管理。
- 记账、改预算、改订阅或每日零点自动触发刷新。

### 1.3 顺手小体验与推广收口（P1）
- **长按首页账单「复制一笔」**：自动带入金额、商户、分类、账户、备注，日期默认今天，保存后生成新记录（不带原图附件）。
- **README 动图演示**：录制 3 个 5 秒真实操作 GIF（离线语音拆单 / 批量导截图 / MCP 问 AI 查账）放至 README 顶部。
- **跨端视觉对齐**：按 `docs/DESIGN_SYSTEM.md` 逐步将 Windows 安装向导与 Wallos 桌面端的旧蓝色 `#426de5` 统一为清衡青绿。

## 2. 中期计划：`v1.48`（精细管钱与横向归集）

### 2.1 分类预算与超支提醒（P1）
- 在现有月度总预算下方支持为重点分类（餐饮、购物、娱乐等）设置独立子预算与进度条，达 80% / 100% 清晰标色或提醒。
- 全部存入 `BudgetPreferences`，不破坏交易表与同步协议。

### 2.2 轻量级标签（Tag，P1）
- 保留现有 15 个核心主分类不变，支持给任意账单打多个横向事件标签（如 `#旅行`、`#装修`、`#出差`、`#宠物体检`），支持按标签筛选与汇总总开销。

### 2.3 多云对象存储备份扩展（可选，P2）
- 在 WebDAV 基础上视用户反馈扩展 S3 兼容协议（Cloudflare R2 / 阿里云 OSS / MinIO）。

## 3. 远期低优先级池（Backlog — 明确低优先级，视精力与反馈启动）

> 以下功能复杂度高或需要跨端/协议大改，**当前不排入近期开发**，先沉淀设计思路以备将来启用。

### 3.1 轻量资产账户与净资产体系（低优先级）
- **多账本**：按场景隔离独立账本与币种。
- **完整账户余额与平账校准**：未来如启动，**严禁采用易漂移的增量加减余额**，优先采用「**锚点余额（`anchorBalanceCents` + `anchorAtMs`）+ 锚点后流水实时派生计算**」的架构；平账校准即更新锚点，不生成污染统计的假流水。
- **账户互转与信用卡增强**：`toAccount` 双边转账、信用卡额度 / 欠款 / 溢缴款 / 出账日与还款日。

### 3.2 苹果生态（iOS 客户端，低优先级）
- **核心交互平替**：iOS 无法读第三方支付通知与屏幕，改用 **App Intents + 快捷指令「轻点背面截屏静默识别记账」** + Siri 语音 + 桌面小组件 + 对接现有 `sync_v2` 同步。
- **分发路线**：
  - 零成本极客版：GitHub Actions 免费 macOS runner 编译 `.ipa` + AltStore / SideStore / iPASide 自签源（有 7 天续签限制）。
  - 大众体验版：开通 Apple Developer（$99/年）走 **TestFlight 公开链接**（免国区 ICP 备案，上限 1 万人），成熟后再评估正式上架 App Store。
- **协议前置注意**：当前仓库为 GPLv3，若未来上架 App Store 需提前对 iOS 客户端/共享核心做 MIT/Apache-2.0 双授权处理。

### 3.3 可持续商业化备选方向（低优先级，严守开源承诺）
- **红线**：绝不把已开源免费的本地核心记账能力重新锁进会员墙。
- **体面方向**：
  1. **官方托管「清衡云同步 + 托管 MCP 服务」**（按月/年订阅，卖服务器成本与免运维省心，自建永远免费）。
  2. **iOS App Store 买断制**（覆盖苹果开发者年费与审核成本）。
  3. **1 对 1 付费代部署 / 私有化配置服务**（面向不会用 Linux/VPS 的用户）。
  4. **纯外观主题 / 社区自愿赞赏**。

---

## 4. 明确不做（Out of Scope / 伪命题过滤）

以下方向经真实用户场景评估，与清衡「无感省心、克制精准」的基因冲突或维护成本过高，**长期不做**：
- ❌ **App 内置 AI 聊天窗口 / 绑定大模型中转 API**（坚持外部 AI + MCP 架构）。
- ❌ **自动退款 / AA 垫付强关联冲抵原支出**（自动匹配无法做到高可靠，极易弄乱账本原流水与同步口径）。
- ❌ **统计页「隐藏转账 / 仅看真实消费」单独开关**（已有单笔不计入与清晰分类）。
- ❌ **App 内置指纹/面容应用锁**（国产 Android 系统均已自带应用锁，重复叠加徒增打开阻力）。
- ❌ **首页金额「小眼睛」打码按钮**（不增加冗余顶栏控件）。
- ❌ **报销发票 ZIP 打包流程**（企业报销核心凭证是电子发票 PDF，非付款截图）。
- ❌ **炫技型社交功能**（可分享交易小票、连续打卡蜂迹等）。
