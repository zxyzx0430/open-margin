# 清衡 v1.3.1-rc.5（RC）

这一版把日历改回原来的操作方式，另外统一了导入入口、缩短了长按时间。

## 日历：回到原来的交互

- **点一下**某天：选中这一天
- **长按后拖动**：选一段日期，拖过哪些天就选到哪些天，拖动有触感
- **跨月拖动**：拖到月份首尾的空白格，停留 350ms 自动翻页；反向拖 24dp 解锁后可退回
- **横向滑动**：不再切换日期，恢复为「滑动月份标题栏切月」的旧行为
- **清除**：选中区间后，汇总卡右侧的「清除选择」按钮，以及右上角 ⋮ 菜单里都能清
- **月份选择**：点顶部月份标题，弹出「选择月份」面板，可直接跳年和月（新增，方便跳远月份）
- 没有选中时显示本月汇总；有选中时列出该区间账单

## 账单页入口统一

- 账单页右上角的下载按钮，现在弹出的是和设置页**同一个**「导入 / 导出账单」底部面板，不再是原来那张全屏导入页。

## 长按时间

- 右下角「+」长按开录音的时间从 1 秒缩短到 **0.75 秒**；不足 0.75 秒松手仍是普通点击（打开新建账单）。
