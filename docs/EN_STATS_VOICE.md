# English layout fixes: stats and voice capture

## Statistics
- 问题：窄屏下等宽时间范围按钮给英文标签留白不足，收支按钮也可能被裁。改法：缩小水平内边距、单行省略，并将“月度”英文收短为 `Month`。
- 问题：汇总卡与日汇总的英文标签过长，图例分类名可能挤压金额；趋势标题和日均金额也共用一行。改法：收短关键标签、限制图例金额/百分比宽度、分类名弹性省略，并将趋势标题与自动缩放金额分开排布。
- 问题：分类中心说明、空状态副标题和按钮文案长度不同。改法：中心说明最多两行省略；空状态文案保留自然换行，卡片内容随文字增高。

## Voice capture
- 问题：英文状态提示较长，会挤压“停止/取消”区域；录音状态徽标也可能过宽。改法：缩短状态/隐私文案，状态提示最多两行并省略，徽标保持单行。
- 问题：小屏上“取消 / 重说 / 填入”三个操作无法并排。改法：操作区改为可换行布局，主按钮设最小宽度，空间不足时独占下一行。
- 问题：短屏上面板内容可能超出可视区域。改法：面板内容区支持纵向滚动，保证状态、操作按钮和隐私说明可访问。
