# 清衡 v1.2.3

三件事：采集不再重复录入、状态面板重做、详情页可以改全部字段。

## 采集自动合并

同一笔微信/支付宝支付，如果通知抓取和支付成功页各扫到一次，以前会存两条并弹「待确认重复」。现在自动合并成一条：

- 同来源、同金额、同方向、时间差 2 分钟内，且一方有商户/订单号 → 合并
- 保留先入库那条的 id，把商户、订单号、分类补给进去，不新增一行
- 已经重复过的那一对，升级后会做一次自动纠正
- 仍会进人工确认的：来源不同（手工 vs 微信）、商户明显不同、超过时间窗

## 状态面板重做

- 同步状态：一行「圆点 + 同步正常 + 刚刚」，待上传与冲突合成一行摘要，展开/复制改成小按钮，立即同步固定在底部
- 常驻运行状态：标题只出现一次，去掉秒级计时；说明收进「通知栏没有显示？」折叠项；大按钮改成普通次级按钮

## 详情页全字段编辑

点「编辑」进入全屏编辑页，底部固定「删除 / 取消 / 保存」：

- 可改：金额、收支类型、分类、商户、备注、账户、来源、发生时间、审核状态
- 只读：id、服务器同步状态、本地改动标记、重复标记
- 保存后同步到服务器，网页端能看到同样的修改
