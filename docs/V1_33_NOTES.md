# 清衡 v1.33

正式版。新建账单重新做成底部面板，切换语言不再闪黑，补掉几处边界问题。

## 新建账单

- 点右下角 +，从底部升起面板（与长按语音输入同一套界面），不再是居中弹窗。
- 面板约占 88% 高度，键盘弹起不遮挡字段；一句话记账、支出/收入、日期金额、分类商户、账户、备注都在面板里。
- 保存失败不再丢输入：写入成功才关闭面板；失败保留全部内容并提示，可直接重试。
- 保存中按钮禁用，避免重复记账。

## 语言切换

- 中英切换不再闪黑屏：关闭窗口过渡动画，重建时直接呈现新语言界面。

## 其他修复

- 语音提示文案与 0.75 秒长按阈值一致。
- 统计页「笔数」与金额口径统一：非 CNY、重复、排除项同时不计入笔数。
- 导入账单先检查文件大小，超过 20 MB 直接提示，不再先读进内存。
- 日历分屏 / 短屏下整页可滚动，六行月份格子自适应 44–48dp，金额不被裁切；长按拖动与跨月翻页行为不变。

- versionCode 33 / versionName 1.33
- 覆盖安装保留数据
