# English layout overflow fixes

## A. Import / export bottom sheet (`BillImportExportSheet`)

| 问题 | 改法 |
|---|---|
| 英文标题与说明较长，标题可能挤压关闭按钮，说明可能占满横向空间 | 标题最多两行并提供省略保护；说明显式占满内容宽度、最多三行。 |
| “Choose bill file” / “Export all bills” 按钮文字可能挤压药丸背景 | 两个全宽按钮的文字居中，最多两行并约束溢出；预览列表改为面板剩余高度内滚动，避免整张面板超出可用高度。 |
| 导入预览的状态、行号、日期、金额争抢宽度；商户名和分类容易被切 | 元数据行限制为单行并对日期使用权重；金额使用不省略的自适应金额文本并保留最小宽度；商户占剩余空间并省略，分类单独显示并限宽。 |
| 汇总与成功/错误反馈在英文下变长 | 汇总计数拆成可换行的 `FlowRow` 项；结果和错误文本显式使用内容宽度并限制最大行数，避免撑破面板。 |

## B. Transaction list screen

| 问题 | 改法 |
|---|---|
| 顶部采集/同步状态胶囊英文变长 | 状态行保留水平滚动，胶囊完整可达，不挤压账单内容。 |
| 搜索 hint `Search merchant, note or exact amount` 在单行输入框中偏长 | 列表页使用精简 hint `Merchant, note or exact amount`，单行显示并以省略号兜底。 |
| 分类、支出、收入筛选 chips 在英文下横向排不下 | 保留可水平滚动的筛选行，窄屏可横向查看，不压缩 chip 文案。 |
| 日期分组标题与右侧支出/收入金额争抢宽度 | 标题使用权重和单行省略；金额右对齐并用自适应金额文本；排除项计数放到次行。 |
| 商户名、审核状态和 `[Scanned]` / 分类 / 来源 / 时间副标题争抢空间 | 商户名与副标题各占可用剩余宽度并单行省略；审核状态也有省略保护。 |
| 行金额可能挤压商户区，图标需要保持宽度 | 金额区至少保留 80 dp 并使用自适应字号、不用省略号；分类图标维持 42 dp 固定尺寸。 |
