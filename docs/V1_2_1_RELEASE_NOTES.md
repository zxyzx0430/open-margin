# 清衡 v1.2.1

这次是「账本完整性 + 界面收敛」的修复版，重点解决导入的历史账单被丢弃、同步一卡到底、以及一批视觉不一致。

## 账本完整性（服务端 + App）

- 服务器不再按「账本起始日」丢弃任何记录：SQLite 触发器、v1 上传、v2 写入、CSV 导入、手工记账五处闸门全部拆除。
- 导入的旧账单（早于 2026-10-10）现在会完整入库，手机和网页看到的是同一份账本。
- 订阅预测仍以账本起始日为边界，只影响“未来还要扣多少”，不影响历史数据。
- 旧版服务器返回“有记录未接收”时，App 只提示条数，不再阻断整条同步链。

## 同步界面拆分

- 「最近同步」只打开状态页：状态词、最近成功时间、待上传条数、逐笔冲突（日期、商户、金额、来源与字段级差异）、最近一次结果原文（可复制）、立即同步。
- 「同步设置」只打开配置页：服务器地址、密钥、开关、首次连接向导；「更换服务器」置底并二次确认。
- 「待上传」和「真冲突」分开计数，本地改了还没上传不再被说成冲突。
- 状态胶囊按严重程度着色：阻断 / 授权失败为红色，冲突为橙色，正常为绿色。

## 日历

- 长按进入区间选择后，拖到最左 / 最右列继续拖会自动翻月，区间终点落在目标月首日 / 末日；往回拖会翻回来。
- 修复日历页顶部重复留白。

## 视觉

- 常驻通知改为「清衡 OpenMargin」+ 一行状态，不再展开三行，也不显示秒级计时。
- 金额不再被省略号截断，按可用宽度自动缩小字号（下限 11sp）。
- 设置页每行标题与副标题固定单行，放不下靠精简文案解决；列表里的服务器地址只显示主机名。
- 清理防御性文案：删掉“不代表/不表明”这类免责补充，保留功能说明与操作后果。
