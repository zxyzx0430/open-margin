# 扫码页布局与交互

扫码连接继续使用项目已有的 `zxing-android-embedded` 4.3.0、`ScanContract` 和二维码解析流程；只替换捕获页外观，不更换配对协议或回调契约。

## 布局

- 相机预览全屏铺底，窗口和预览背景为黑色。
- 取景框外使用 `#8C000000` 黑色蒙层（约 55% 不透明度）；取景框尺寸由 ZXing 预览配置为 270dp 方形。
- 取景框四角以白色短线标出，和 ZXing 实际解码框共用坐标；关闭扫描线和候选结果点，框内不绘制红/绿装饰。
- 顶部左侧为关闭按钮，右侧为手电筒开关；按钮图标使用项目已有的 Material Icons。底部白字提示为「将电脑上的二维码放入框内」。

## 交互与兼容性

- 关闭按钮仅结束捕获页；扫码结果仍由 `CaptureManager` 交回 `ScanContract`，上层 `PairingQrScanAction` 的成功、拒绝和权限失败回调保持不变。
- 手电筒通过现有 `DecoratedBarcodeView.setTorchOn()` / `setTorchOff()` 控制。当前仓库的扫码后端是 ZXing Android Embedded（Android Camera API），没有 CameraX 依赖或 `CameraControl`，因此不新增依赖并使用该后端提供的等效开关接口。
- 不实现点击预览对焦：当前 ZXing 后端提供自动对焦管理，但没有公开的点按测光/对焦 API；CameraX 的 `CameraControl` 当前不可用。自动对焦仍按后端默认行为运行。
- 相机权限仍由启动扫码的 Compose 调用方在启动捕获页前申请；相册解码、成功/无效二维码的处理逻辑不变。

- [ ] 有效配对码成功返回、无效配对码仍走原拒绝回调。
- [ ] 关闭按钮、系统返回键和相机权限拒绝路径。
