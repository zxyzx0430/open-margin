# 清衡 v1.2.4

这一版集中处理「看起来累、点起来不顺」的问题。

## 账单列表与详情

- 列表行不再展开：去掉箭头和那排「不计入统计 / 添加分类规则 / 编辑 / 删除」，整行点击直接进详情
- 详情页重做，一屏放下、不滚动：金额主视觉放在顶部卡片，下面一张字段卡（收支类型、分类、账户、来源、发生时间），备注单独成卡，最多三行
- 底部固定操作区：不计入统计 / 添加分类规则，编辑 / 删除
- 列表与详情不再出现「未核实」；审核状态只在已确认、不计入、转账、退款时显示
- 删掉旧的「服务器同步」「本地改动」两行，同步状态改成标题栏右侧小胶囊

## 统计

- 环形图占比 ≥6% 的分片直接标「分类名 + 百分比」，不再只靠颜色
- 「+N 类」可点开，显示剩余分类，再点收起
- 分类明细每一个行都可以点，进入那笔交易详情
- 结余、日均、较上一年金额不再被裁切

## 日历

- 跨月需要停留：拖进空白格后停 350 毫秒才翻一页，翻完必须重新停留
- 翻月时震动一次，月份标题淡入，手上有反馈
- 反向拖回同样要停留，不会连跳两三个月

## 更新

- 检查到新版本会弹出下载提示：显示版本、大小、日期与更新说明，可选「取消」或「下载」
- 下载完成后校验文件大小，再拉起系统安装界面
- 首次安装需要授予「安装未知应用」权限，App 会直接跳到该设置页
- 去掉「检查更新仅访问公开 Releases…」那行补充说明
