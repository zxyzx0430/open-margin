# 清衡 1.42

`versionCode 43` / `versionName "1.42"`

## 主动截图记账与原图留证

- 支持批量导入微信 / 支付宝付款截图（一次最多 10 张），双击首页「+」按钮或直接从系统相册分享即可快速入账
- 截图识别入账时自动压缩保存原图在本机（仅本机存储、不参与同步，默认保留 90 天 / 上限 100MB 自动清理），账单详情与编辑页随时可点开核对原图
- 高置信且已完成的付款、转账、退款、红包与提现支持自动入账，未完成或方向不明的交易保留到待确认；删单后手动重传同一张截图不再误判为重复拦截

## 自动记账加固与诊断

- 加固通知与页面识别的跨通道去重和字段补全，降低重复入账与静默漏单风险
- 精简账单诊断日志卡片，新增「仅失败与警告」筛选、搜索清空、点击直达账单详情与完整链路复制

## 界面与交互焕新

- 首页底部「+」按钮支持三手势：单击手动记账、双击批量导截图、长按本地语音记账
- 重做新建账单、语音记账面板、自研滚轮日期时间选择器、设置页分组与 5 个设置弹窗，并更新新手引导
- 新增应用内站内更新提示，后续发版可直接感知与下载
