# 清衡 v1.3.1-rc.6（RC）

这一版集中修英文模式下的排版溢出，并补全日历的显示设置。

## 英文排版

- 预算页：「Adjust budget」不再被药丸背景裁切，四列预算数据不再换行挤断。
- 新建账单：「11/17」日期不再竖排；Merchant 输入框文字单行省略；账户 None / WeChat / Alipay 三个 chips 完整可点，不再切掉半个。
- 统计页：时间范围、汇总标签、图表图例、分类排行在英文下完整显示。
- 账单列表：顶部状态胶囊、搜索提示、筛选 chips、日期分组头、行副标题都按英文长度重排。
- 导入 / 导出面板：标题、说明、两个主按钮、预览列表与结果提示不再被截断。
- 语音面板：提示语与停止 / 取消按钮在英文下完整显示。

## 翻译

- 反馈弹窗的诊断信息改为跟随语言：版本 / 机型 / Android / 语言 / 说明，英文模式下全英文。
- 设置项「导入账单」改为「导入 / 导出账单」（Import / Export bills），与实际功能一致。
- 扫掉其余 UI 可见但未翻译的硬编码中文。

## 日历

- 新增独立设置「日历数字」：支出 / 收入 / 结余 / 不显示，在日期数字下面显示当天合计。
- 农历开关保持不变，与日历数字可自由组合：只农历、只数字、都显示、都不显示。
- 热力图改为 4 档分位：按当月 P50 / P75 / P90 切档，固定深浅，不再被单日大额压平；有记录天数少于 4 天时退化为单档。
- 选中日期或区间后，下方账单变成可上拉抽屉：默认露出 40%，上拖到 85%，内部独立滚动，不再像被截断。

## 其他

- versionCode 31 / versionName 1.3.1；覆盖安装保留数据。
