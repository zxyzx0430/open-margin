# 清衡 v1.34

新建账单按「金额优先」重做，语音面板回到原来那版。

## 新建账单（方案 A）

- 面板高度跟着内容走，不再固定 88%，底部不留空。
- 打开即聚焦金额，直接弹数字键盘；金额是主视觉，大字号。
- **一句话记账（详细版）**：三行输入，带示例「午饭 25 微信」；输入停顿约 0.5 秒自动解析并回填，不需要点识别按钮。
  - 解析结果以 chips 显示（金额 / 分类 / 商户 / 账户），可逐项取消。
  - 认不出金额不猜，提示手填；手动改过的字段不被后续解析覆盖。
- **日期、分类、账户全部是选择器**，不是输入框；账户 chips 横向滚动。
- 商户、备注保持文本输入（可选）。
- 保存成功才关面板；失败保留全部输入并提示；保存中按钮禁用。

## 日历

- 恢复长按拖动选日期：去掉整页滚动，长按手势不再被滚动容器抢走。
- 分屏 / 短屏仍按格子高度自适应（44–48dp），跨月翻页保持原样（拖出网格仍可翻月）。

## 语音面板
