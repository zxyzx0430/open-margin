# 清衡 v1.32

这次主要是日历的操作与视觉，加上系统层的中英文支持。

## 日历

- 顶部「支出 / 收入 / 结余」改为三等分铺满，不再挤在左边贴边。
- 日期下面的金额不再被格子裁掉；六行月份也能完整显示。
- 选中日期或区间后，下方账单变成抽屉：
  - 顶部把手居中，往上甩一下展开到 85%，往下甩一下收起。
  - 单日显示「11月15日 · 2 笔 · 支出 ¥2.50」+ 账单列表。
  - 区间显示「11月2日 – 11月15日 · 14 笔」+ 支出 / 收入 / 结余 一行统计 + 账单列表。
  - 抽屉里不再重复四格大数字。
- 右上角菜单按组整理：
  - 日期高亮：开 / 关；开启后展开支出、收入、结余三选一。
  - 日历数字：开 / 关；开启后展开支出、收入、结余三选一。
  - 周起始日、农历、清除选择保持原样。
- 热力图改为 4 档分位（P50 / P75 / P90），不再被单日大额压平。
- 点月份标题弹出选择月份：底部左侧「回到本月」、右侧「取消」，纵向空白收紧。

## 系统级中英文

- 切换英文后，多任务 / 分屏标题、通知栏 App 名、桌面图标名都显示 Open Margin；切回中文恢复清衡。
- 通知渠道名称与常驻通知文案跟随语言，英文模式下不再出现中文。

## 其他

- 预算页、统计页、账单列表、新建账单弹窗、导入 / 导出面板、语音面板的英文溢出修复。
- 反馈诊断信息按语言显示；设置项改为「导入 / 导出账单」。
- 账单页右上角与设置页共用同一个导入 / 导出底部面板。
- versionCode 32 / versionName 1.3.2；覆盖安装保留数据。
