# Wallos 原生预测显示口径校正 · 2026-10-12

该补丁仅修改 Wallos 原生统计页面的预测标签，不修改 Finance 流水、预算、续费时间、订阅价格或汇率源。

## 问题

原生 Wallos 的 `IntlDateFormatter($lang,..., 'MMM yy')` 将最高订阅费用月份渲染为“5月 27”，容易误读成 5 月 27 日。预测实际从**下个月开始覆盖未来 12 个自然月**，在 2026-10-12 时为 2026-11 至 2027-10。

## 现有数据核对

2027-05 计划付款合计约 CNY 332.31：
- ChatGPT Plus USD 19.99，约 CNY 133.78；
- VPS 年付 USD 21.88，约 CNY 146.42，计划续期 2027-05-13；
- 月度手机套餐 CNY 47；
- CLS 港卡 HKD 6，约 CNY 5.11。

该预测是当前 Wallos 订阅配置和最新存储汇率下的参考，不代表真实扣款。部分手机/港卡扣费日尚待核实。VPS 年费与每月固定项目叠加，构成峰值。

## UI 修改

- 大卡片时间改为“2027年5月”，而不是“5月 27”。
- 横轴标签明确用“27年5月”（年月顺序）。
- 将指标表述为“未来12个月订阅计划扣费最高月份”。
- 将图表表述为“未来12个月预计订阅扣费（非真实消费）”，并解释下个月起算、年付费用集中到对应月份。
- 不改变原生 Wallos 的预测桶、周期推进与金额计算；动态汇率由 Wallos 原有任务管理。

## 测试与回滚

预测代码仅包含 stats.php 这一处覆盖；必须 PHP lint、独立 Wallos 镜像构建和部署文件哈希检查通过。保留发布前的数据库一致性备份与旧镜像，失败自动回滚。
