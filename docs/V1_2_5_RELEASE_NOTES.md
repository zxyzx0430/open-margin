# 清衡 v1.2.5

视觉收尾版：详情页按钮统一、环形图重做、日历英文补齐。

## 账单详情

- 底部按钮改成统一栅格：所有按钮同高 46dp、同圆角 12dp、左右边距统一 16dp
- 第一行「不计入统计」「添加分类规则」等宽 tonal 按钮，间距 12dp
- 第二行「编辑」主按钮占 2/3，「删除」改成 error 色描边按钮占 1/3，不再是裸红字
- 行间距 10dp，底部留出系统手势区

## 统计环形图

- 去掉贴在环边的文字，改成引线标注：径向短线折水平线，末端写「分类名 + 百分比」，左对齐/右对齐按扇区位置分侧
- 左右两侧分别做防重叠排布，只标前 6 大
- 点扇区：该块向外偏移 8dp、引线与标签变色、中心金额切换为该分类金额与占比；再点恢复总计，200ms 动画
- 图例对应行同步高亮

## 日历英文

- 底部 tab、页面标题补上 `Calendar`
- 月份与日期按语言格式化：中文 `2026年11月` / `11月21日`，英文 `November 2026` / `Nov 21`
- 同月与跨月区间的显示统一走同一个格式化函数
- 新增翻译覆盖率测试：源码里所有 `tr("…")` 的中文 key 与英文表求差集，缺一条即失败
