# English UI overflow audit

## 日历页（CalendarScreen）

### 发现的问题与改法

- **月份标题**：英文全月份名（如 `September 2026`）与前后月按钮、设置图标共用一行。标题改为单行并加省略号兜底，保留图标触控区。
- **汇总指标**：支出、收入、结余与笔数原先挤在同一水平行，英文标签和金额会互相挤压。保留原统计口径，将四项改为两行两列、标签置上、数值置下；长标签单行省略，金额使用已有自动缩字号组件。
- **区间标题与清除按钮**：跨月英文日期范围可能挤压右侧按钮。标题占用剩余宽度并单行省略，清除按钮保持短文案。
- **菜单项**：英文前缀加选项名可能超过菜单宽度。菜单文字统一单行省略，独立列出日期高亮、日历数字、农历与周起始日设置。
- **日期格第二行**：新增与日期高亮互不影响的「日历数字」设置（支出 / 收入 / 结余 / 不显示），默认不显示；原农历开关保留并单独持久化。支出、收入和结余按当天有效记录合计；无对应记录留空，不显示零金额。金额按分整数格式化并紧凑显示。
- **日期格组合**：只农历＝日期 + 农历；只数字＝日期 + 金额；两者都开＝日期 + 农历 + 金额（收紧三行字号与行高）；两者都关＝只有日期。英文模式不显示未本地化的农历汉字，英文日期和数字金额继续显示。
- **热力图分位档**：热力样本仅取当月所选指标为正的日期；0 金额或无记录日期保持透明。至少 4 个有效日期时按最近秩 P50/P75/P90 划分 `≤P50`、`(P50,P75]`、`(P75,P90]`、`>P90`，alpha 固定为 0.08 / 0.14 / 0.20 / 0.28；少于 4 天时所有有正金额日期统一为 alpha 0.14。选中日与区间底色优先于热度。边界、空样本及少样本退化均有纯 JVM 测试覆盖。
- **隔离验证**：单测覆盖逐笔合计、空日期、负结余、紧凑中英文金额、菜单文案、英文日期及热力分位边界。未改点选/区间/跨月手势或汇总统计口径。

本分支按最新分工仅修改日历页、对应纯 JVM 测试和本审计文档；账单、统计、设置、导入/导出与语音页面由其他 Agent 排查，不在此处声称已审。
