# 清衡 v1.35

新建账单面板压成紧凑上拉栏，顺手清掉设置页多余卡片、统一账单来源标签。

## 新建账单

- 面板高度跟内容走，约占屏幕一半到三分之二，不再是近满屏的弹窗；背景遮罩能看到。
- 外壳与语音面板同一套：同样的 24dp 顶圆角、上拉动画、把手与标题行、左取消 / 右实心保存。
- 字段收紧：一句话记账两行（带示例「午饭 25 微信 / 打车 18 支付宝」），金额单行 28sp，日期 56dp pill，分类一行，账户一行 chips，商户单行，备注最多两行。
- 自动识别、chips 取消、不覆盖手改字段、保存失败保留输入，全部保留。

## 设置

- 去掉顶部「自动记账设置 / 已开启」绿色卡片；权限与运行状态仍逐项显示。

## 账单列表

- 每笔都显示一个来源标签：扫描 / 导入 / 通知 / 短信 / 手动 / 其他来源，不再出现有的有标签、有的没有。
- 英文同步：Scanned / Imported / Notification / SMS / Manual。

- versionCode 35 / versionName 1.35；覆盖安装保留数据。
